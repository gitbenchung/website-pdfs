# website-pdfs
I upload files (e.g., CVs, papers, etc.) to host on my website.
# All external links use <<https://gitbenchung.github.io/website-pdfs/PATH>> on site
Example path name for CVs: cv-firstname-lastname-Month.abbrYear.pdf (e.g., cv-ben-chung-Sep2024.pdf)
<br> Example path name for articles/presentations: first author-second author*-et_al**-year.pdf (e.g., Chung-2024.pdf; Turin-Chung-2018.pdf; Carpenter-et_al-2021.pdf) </br>
